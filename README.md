# Stack The Rat

Web app gratuita e open source per visualizzare lo **stack** di Magic: The Gathering:
magie e abilità in pila, frecce verso i bersagli, risoluzione manuale.

- Installabile su iPhone e Android dal browser ("Aggiungi a Home"), senza store.
- Dati delle carte da [Scryfall](https://scryfall.com).

## Sviluppo

```sh
npm install
npm run dev
```
